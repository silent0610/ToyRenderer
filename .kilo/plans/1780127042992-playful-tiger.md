# Plan: BruteForceSdf 增加软件光追符号真值生成

## 目标
在 `BruteForceSdf` 中新增一个方法，仅用射线求交计算每个体素的 inside/outside 符号（+1/-1），不计算距离，大幅提升符号验证的效率。

## 核心思路
现有 `GenerateGroundTruth` 调用了 `FindClosestDistance`（BVH遍历找最近三角形距离）+ `IsPointInsideMesh`（射线求交判内外）。符号真值只需要后者——对每个体素中心发射一条射线，统计与 mesh 的相交次数，奇数次为内部（-1），偶数次为外部（+1）。

复用已有的 CPU 侧 BVH 和 `IsPointInsideMesh`/`IntersectRayAabb`/`IntersectRayTriangle` 逻辑，同样用 ThreadPool 并行加速。

## 需要修改的文件

### 1. `Renderer/Source/Function/BruteForceSdf/BruteForceSdf.ixx`
- 新增公开方法声明 `void GenerateSignField(std::vector<float>& signData)`
- 新增私有辅助方法声明 `int ComputePointSign(const glm::vec3& point) const`（封装 `IsPointInsideMesh` 返回 ±1）

### 2. `Renderer/Source/Function/BruteForceSdf/BruteForceSdf.cpp`
- 实现 `GenerateSignField()`：
  - 与 `GenerateGroundTruth` 相同的并行框架（ThreadPool按z层分发）
  - 相同的体素坐标翻转逻辑
  - 区别：每个线程调用 `ComputePointSign`（仅射线求交判内外）而非 `FindClosestDistance`
  - signData[i] = 1.0f (outside) 或 -1.0f (inside)
- 实现 `ComputePointSign()`：
  - 返回 `IsPointInsideMesh(point) ? -1.0f : 1.0f`

### 3. `Renderer/Source/Renderer.cpp`（可选，便于测试调用）
- 在 `TestBruteSdfAndSave` 中或新增一个按键触发调用 `GenerateSignField`，验证并保存结果

// 封装 IsPointInsideMesh 返回 ±1
int BruteForceSdf::ComputePointSign(const glm::vec3& point) const
{

## 复杂度与收益
- 时间复杂度：O(V * log(T)) 其中 V=体素数，T=三角形数（BVH剪枝后平均每根射线只测少量三角形）
- 相比当前 `GenerateGroundTruth`（每个体素要遍历整个BVH找最近三角形距离），符号场计算快 **10-50 倍**
- 结果可直接用于：验证 JFA/深度融合等方法的符号正确性，给无符号 SDF 添加符号
